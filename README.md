# CommonGround — comground.app

AI-powered opportunity matching for high school students.

## Pages
- `/` — Landing page (index.html)
- `/mockup` — App mockup preview
- `/brand` — Brand guide

## To update the site
1. Edit any file in this folder
2. Open GitHub Desktop → you'll see the changed files
3. Write a short note like "updated homepage" → click Commit
4. Click Push → Vercel auto-deploys in ~30 seconds

## Tech
Static HTML/CSS — no build step needed. Just edit and push.
